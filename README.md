# El tribunal

Recurso web 3D para el alumnado del Grado en Educación Primaria (FCEDU, ULPGC), basado en *La oposición* de Alfonso Mateo-Sagasta. El estudiante actúa como cuarto vocal del tribunal y contrasta cinco estaciones con la historiografía.

- Sin instalación ni servidor propio: es una página estática (`index.html`) con la sala 3D (`sala.glb`) y el panorama de reflejos (`sala_env.hdr`).
- Código fuente, modelado en Blender y texturas: carpeta `fuentes-3d/`.
- Licencias y créditos: `LICENCIAS.md`.

## Publicación con GitHub Pages

1. Crea un repositorio público en GitHub (por ejemplo, `el-tribunal`).
2. Sube **el contenido** de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz, junto con `.nojekyll`).
3. En el repositorio: *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save*.
4. Espera uno o dos minutos. La dirección será `https://TU-USUARIO.github.io/el-tribunal/`.
